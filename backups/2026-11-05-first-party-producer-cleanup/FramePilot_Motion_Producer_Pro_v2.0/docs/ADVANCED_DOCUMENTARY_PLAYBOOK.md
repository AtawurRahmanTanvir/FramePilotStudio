# Advanced Documentary Playbook

## 1. Narrative backbone

For each video, identify:

- **Cold open:** a concrete contradiction, question, consequence or image.
- **Promise:** what the viewer will understand by the end.
- **Context:** the minimum facts required to orient the viewer.
- **Mechanism:** how the system/business/technology actually works.
- **Evidence:** objects, source-backed figures, documents, chronology or direct comparison.
- **Turning point:** the event or decision that changes the trajectory.
- **Consequence:** measurable or clearly described effects.
- **Payoff:** resolve the opening question and add a deeper implication.

Do not force a section into this structure if the script intentionally follows another form. Preserve the approved script's actual narrative.

## 2. Claim / evidence register

Each central claim should have:

- Claim ID and exact script excerpt.
- Claim type: historical, financial, operational, legal, technical, interpretive.
- Source supplied by user or verified source reference.
- Visual evidence type.
- Confidence / limitation.
- Whether the visual is literal or metaphorical.

Do not create a visual that turns an allegation into a proven finding. Do not make a chart from a qualitative adjective. Do not use a decorative number that viewers may read as a real metric.

## 3. Visual explanation types

Use the visual type that explains the mechanism best:

- Chronology: timeline, era card, map evolution.
- Scale: properly sourced comparison, map, object size.
- Process: step chain, system diagram, process animation.
- Causality: linked stages, before/after, decision fork.
- Market shift: value-chain map, revenue model, distribution network.
- Technology: exploded view, component relationship, signal flow.
- Geography: map with correct route and location evidence.
- Identity: supplied product/brand/object evidence, not a fabricated logo.
- Abstract concept: simple metaphor, explicitly not documentary evidence.

## 4. Long-form pacing

For videos over 10 minutes:

- Plan chapter-level rhythm before local motion.
- Create visual variation inside a coherent design language.
- Avoid a long run of identical static images or identical infographic layouts.
- Avoid rapid cuts that prevent evidence from being read.
- Use pauses and holds after dense information.
- Track cumulative asset use so one chapter does not consume the entire supplied asset set.
- Preserve all mandatory image serials; do not lower the planned asset count without authorization.

## 5. Scene density audit

For each minute estimate planned visual beats, not a forced target. Record:

- Number of major scene beats.
- Number of unique supplied images used.
- Number of reused assets.
- Time an important label/chart remains visible.
- Whether narration continues through the visual transition.

If there is no source-grounded visual for a passage, mark it as a gap. Do not auto-fill with a generic stock-like visual description that invents a fact.

## 6. Series consistency

For a multi-video channel:

- Share typography scale, safe areas, transition grammar and finishing restraint.
- Maintain per-company/topic accent colors only where the brief approves them.
- Ensure focal objects remain distinct across thumbnails and videos.
- Keep visual grammar consistent without reusing the same scene composition.
- Use the project-specific series guide as authority over the defaults in this playbook.
