Help & Guide

Instructions and troubleshooting for FramePilot Studio.

Audio to CSV
  1. Select the voiceover audio.
  2. Select the matching Visual Mapping CSV.
  3. Choose recognition quality.
  4. Select Generate CSV. The Final Master CSV is saved to the default folder shown in this screen.

The Visual Mapping CSV must include Company, Image_No, Image_File, Exact_Voiceover_Span, Start_Estimate, and End_Estimate. A previous Final Master CSV is an output file, not a Visual Mapping input.

Filmora Timeline
  1. Select a Filmora 15 WFP project.
  2. Select its Final Master CSV.
  3. Choose an Image Folder only when the project needs media relinking.
  4. Select Analyze project. Review the project check before generating output.
  5. Choose motion effects and select Generate WFP.
Current Filmora project requirement

The source WFP must already contain the image clips on a timeline track. Creating a complete timeline from an empty WFP is not supported by the current engine.

FramePilot creates a new project beside the source WFP. The original project is not overwritten.

Output files

Final Master CSV: saved in the default CSV folder. Change it once in Settings.

Filmora project: saved in the same folder as the source WFP, with a FramePilot suffix and a unique name.

Motion effects available
  • Zoom In
  • Zoom Out
  • Pan
  • Pan + Zoom

Advanced options: use Assignment strategy to control effect distribution, Random seed to reproduce the same sequence, and Avoid repeated adjacent effects to reduce back-to-back duplicates. Most users can leave these at their defaults.

Troubleshooting

Audio engine is not ready: this development package does not include the complete offline WhisperX, model and FFmpeg runtime. Audio processing stays disabled until the runtime pack is installed in a release build.

Processing failed: open Activity & QA and read the full diagnostic. Check that the input files are valid and that the required media is accessible.

CSV or WFP validation failed: correct the reported issue before generating a project. FramePilot does not invent missing timestamps.
