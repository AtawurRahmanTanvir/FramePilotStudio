FRAMEPILOT STUDIO 0.1.4 — REPLACEMENT GUIDE
==========================================

এই ZIP-টি তোমার GitHub main source archive-এর উপর তৈরি সম্পূর্ণ source replacement archive। ZIP-এর root-এ সরাসরি project-এর ফাইল ও folder আছে; অতিরিক্ত parent folder নেই।

কীভাবে বসাবে
-------------
1. FramePilot Studio বন্ধ করো।
2. নিরাপত্তার জন্য E:\FramePilot_Studio folder-এর একটি backup রাখো।
3. ZIP Extract করো। Extract destination হিসেবে সরাসরি E:\FramePilot_Studio নির্বাচন করো।
4. Windows যদি “Replace the files in the destination” জিজ্ঞেস করে, “Replace the files” নির্বাচন করো।
5. “Skip files” নির্বাচন কোরো না। Extract শেষে ZIP-এর নতুন files-গুলো E:\FramePilot_Studio-এর একই path-এ থাকবে।
6. ZIP-এ থাকা নেই এমন তোমার অতিরিক্ত local files (যেমন .git, node_modules, .venv, local FFmpeg executable বা model files) মুছে ফেলা হবে না। কোনো folder manually delete কোরো না।

পরীক্ষা
------
VS Code Terminal:

    cd E:\FramePilot_Studio
    npm test
    npm start

npm test সফল হলে নতুন Script-to-Image tab, Filmora stage progress এবং generated-output card পরীক্ষা করো।

GitHub-এ পরিবর্তন Push
----------------------
নিজে পরীক্ষা করে সন্তুষ্ট হলে:

    git status
    git add .
    git commit -m "Add Script-to-Image workflow and improve Filmora progress and output access"
    git push

- Original Master Prompt ছাড়া অন্য project files এই build-এ update করা হয়েছে। তোমার .git folder ও local runtime files এই ZIP-এ নেই, তাই সেগুলো replace/delete হবে না।
